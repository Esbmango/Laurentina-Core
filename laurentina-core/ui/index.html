桌面陪伴

动态球体与独立立绘，随时回到同一个聊天窗口。

与聊天头像分别设置。支持透明 PNG、JPG、GIF 和 WebP 动图，最大 25 MB。

角色资源库

上传 ZIP 角色包，或 WebM、GIF、APNG、WebP。支持透明背景；Live2D 与 Spine 分别加载。

仅调整人物，不改变桌宠窗口大小；放大后部分特效可能超出画面。

超过屏幕可用大小时，人物继续放大，部分画面会被裁切。

按住球体或立绘拖动，单击触碰回应，双击打开面板。图片与角色模型保持透明背景，角色包的动画设置在资源库管理。

触碰回应

单击桌宠随机播放一条回应，双击打开面板。录音直接在本机播放；仅有台词时使用当前声音朗读。

支持 0.15–60 秒的 WAV、MP3、FLAC、OGG，最大 20 MB。不读取聊天或写入记忆。

声音与录音

在本机听清你的话，也用声音回应。

连接已运行的本地语音服务。自定义声音由该服务提供。

适用于本应用的自定义声音。跨语言不自然时可试仅保留音色，声音相似度可能下降；原录音和逐字稿不变。

决定待朗读文字怎么发音，不是参考录音的语言。日语参考声线读中英文时请选择自动跟随文字；录音原文保持原语言，不要翻译。
